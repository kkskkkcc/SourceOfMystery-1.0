# Rejected equipment model drafts

These four chestplates and five swords were rejected by the user. They are preserved only for handoff and must not be treated as accepted assets. Everything in this directory is outside Gradle source sets. Active item classes and models have been restored to the approved implementation.

The previous adapter sources, generated resources, authoring generator, editable .bbmodel files and part manifests retain their original relative paths here. The archived generator resolves its root to this draft directory, so running it does not overwrite production assets. Do not copy these into src/ without a new user-directed redesign and review.
