# BOSS 动画说明

本文件说明为「末影龙化形」BOSS 模型新增的动画，以及如何在 Blockbench 里微调、如何在你的模组里触发。

## 动画总览

文件：`animations/boss.animation.json`（已在 `ysm.json` 里注册为 `boss`）

### 攻击动画（一次性，`loop` 不设置）

> 全部按**魂类 Boss 节奏**重做：`蓄力前摇（慢，可读）→ 出手（快，干脆）→ 打击定格 → 收招`。前摇占约 40%，出手只占 0.15~0.2s。

| 动画名 | 作用 | 时长 |
|---|---|---|
| `boss_melee_thrust` | 近战：长矛突刺（蓄力后拉 → 快刺 → 定格） | 1.1s |
| `boss_charge_thrust` | 近战：**单手侧身蓄力刺**（右手单臂把枪刺出、胳膊伸直，左臂后摆，身体侧身+前倾） | 1.6s |
| `boss_melee_sweep` | 近战：长矛**横劈**（扭腰 + 长枪横挥 80° 扫过 → 定格） | 1.3s |
| `boss_kick` | 近战：前踢（提膝蓄力 → 快踢 → 定格） | 1.0s |
| `boss_ranged_breath` | 远程：龙息（**左手**蓄力抬起 → 快发射 → 定格） | 1.4s |
| `boss_ranged_spear_throw` | 远程：丢长枪（**右手**后摆蓄力 → 快掷 → 定格） | 1.2s |
| `boss_spear_flourish` | 后摇：转枪花式收招（右手抬枪**风车式前后翻** 3 圈 + 双腿张开） | 1.8s |
| `boss_taunt` | 挑衅：抬手勾手（左手抬臂 + 前臂勾动两下） | 1.5s |

### 循环动画（`loop: true`）

| 动画名 | 作用 | 时长 |
|---|---|---|
| `boss_idle` | 待机循环：呼吸起伏 + 长发/腰甲飘动 + 翅膀轻微扇动 | 3s |
| `boss_combat` | 战斗循环：右手持枪备战 + 长发/腰甲大幅飘动 + 翅膀扇动 | 2s |
| `boss_fly` | 悬停飞行（凋零式飘浮·放松姿态）：上下浮动 + 翅膀大幅扇动 + 双脚自然张开 + 长发/腰甲飘动 | 2s |
| `boss_crouch` | 蹲地蓄力（准备起跳前摇）：深蹲 + 身体前倾 + 双臂后收 + 翅膀展开 | 1.5s |

### 过渡动画（一次性，`loop` 不设置）

| 动画名 | 作用 | 时长 |
|---|---|---|
| `boss_land_to_fly` | 落地 → 悬停：下蹲蓄力 → 上升 → 腿悬空/翅膀展开进入悬停态 | 1.2s |

## 关键约定

- 模型正面朝向 **-Z**（脸和眼睛都在 -Z 侧），所以突刺/投掷是往 -Z 方向。
- **左右手分工**：模型里 `longspear` 矛骨在 X 负半轴（右侧），所以**长枪默认右手持**，**左手为空手**。
  - 龙息 → **左手（空手）单臂抬起**发射。
  - 丢长枪 → **右手（持矛手）**投掷。
  - 如果你实际是左手持枪，把 `boss_ranged_breath` 里 `LeftArm` 和 `RightArm` 互换、`boss_ranged_spear_throw` 里 `RightArm` 和 `LeftArm` 互换即可。
- **长矛 `longspear` 在所有动画里都不单独移动**（只写 `[0,0,0]` 或不写），由手臂带动，避免二次位移「武器乱飞」。
- 手臂旋转约定：**X 负值 = 手臂向前/向上抬起**（0 = 自然下垂，-90 ≈ 水平前伸，-180 ≈ 竖直向上），前臂 X 负值 = 屈肘。

## 飘动效果（飘逸）

待机与战斗循环里，长发、腰甲（裙子）做波浪飘动，翅膀做轻微扇动，全部用 `catmullrom` 平滑插值：

| 骨骼 | 说明 | 待机幅度 | 战斗幅度 |
|---|---|---|---|
| `LongHair` | 后垂长发（主飘动） | X ±16° | X ±20° |
| `Hair` | 整体头发（轻微） | X ±3° | X ±4° |
| `Skirt` | 腰甲主裙 | X ±8° | X ±10° |
| `FrontSkirt` / `BackSkirt` | 前/后裙摆（错相位，更自然） | ±5° | ±6° |
| `fly` / `fly2` | 翅膀扇动 | X ±8° | X ±12° |

想更飘逸就加大这几个骨的旋转幅度；想更快/更慢就改循环时长（`animation_length`）。

> `boss_fly` 是 BOSS 的**常态悬停**（凋零式飘浮）：`Root` 上下浮动 ±1.2，翅膀扇动幅度最大（`fly`/`fly2` X ±35°）。做成了**放松姿态**——身体基本竖直（`UpBody` X 仅 4°），双臂自然下垂微张（X -10），**双脚自然张开**（`LeftLeg`/`RightLeg` Z ±14° 外摆，小腿微屈 +15°、脚放松 -10°），整体随气流轻轻晃动。如果这是 BOSS 的默认状态，就把动画控制器的初始状态切到 `boss_fly`；需要从地面起飞时先播一次 `boss_land_to_fly`，播完再切到 `boss_fly` 循环。

## ⚠️ 需在 Blockbench 里确认的一处

### 翅膀旋转方向

`fly` / `fly2` 的扇动和展开用的是 X 旋转。因为 `fly2` 自带 `[180,-70,-180]` 的初始旋转，实际扇动/展开方向和幅度请在 Blockbench 里确认，避免翅膀穿模。若 `fly2` 的扇动方向和 `fly` 相反，把 `fly2` 的 X 值全部取反即可。

## 如何在你的 BOSS 实体里触发

这套动作是标准基岩版动画格式（`format_version 1.8.0`），骨骼名和 `models/main.json` 完全一致。按你的渲染/动画框架任选其一：

- **GeckoLib / 自研基岩动画渲染**：
  - 待机/战斗循环：用动画控制器切换 `boss_idle` / `boss_combat`（循环播放）。
  - 攻击：AI 触发时 `entity.playAnimation("boss_melee_thrust")` 等一次性动画，播完回到循环。
- **YSM 控制器**：把循环挂到 `player.main` 的状态里，攻击挂到 `player.parallel_*` 或按条件触发。
- **发射点**：龙息从**左手** `LeftHandLocator` 出生；长枪投掷时，弹射物从右手（或 `longspear`）出生并飞向目标——具体由你的实体代码处理，动画只负责「抬手/投掷」姿态。

## 常用微调点速查

- 突刺/投掷太慢太快 → 改 `animation_length` 和各关键帧时间点。
- 突刺更狠 → 加大双臂 X 负值（现在 -88）。
- 龙息更夸张 → 加大 `LeftArm` 的 -105 抬臂；投掷更狠 → 加大 `RightArm` 的 -170 蓄力 / -50 出手。
- 横扫更狠 → 加大 `UpperBody`/`UpBody` 的 Y 旋转（现在 ±25 / ±12）。
- 龙息蓄力前摇 → 在 `boss_ranged_breath` 开头加长抬臂/展翼时间，把 `0.4~0.7s` 发射定格后移。
- 待机/战斗飘动幅度 → 调 `LongHair` / `Skirt` / `fly` 的旋转值。
- 长矛在手位置更贴合 → 在 `models/main.json` 调整 `longspear` 相对手骨坐标（或把 `parent` 改到手骨），动画无需改动。
