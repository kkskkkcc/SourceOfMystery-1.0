# 天气掌控与巨型龙卷风

法杖轮盘追加第八种法术「天气掌控」，旧法术 ID/编号保留。L 选术、Shift＋右键循环晴天、雨天、雷暴、巨型龙卷风；长按右键默认3秒完成施法，松开取消不扣费。晴雨雷暴默认每次2000神秘之能、12000tick（10分钟），龙卷风默认5000、6000tick（5分钟），可配置。龙卷风生效时再按右键消散，持续按住施法键不会误关，Shift＋右键仍只换下一次的选择。

晴天／雨天／雷暴使用原版世界天气系统；降雪仍由原版群系温度决定，无天空或有顶维度会拒绝这些原版天气选项且不扣费。龙卷风在准心选取的已加载地表形成；无地形命中时沿用其他地形法术前方落点算法。有顶维度按施法者高度下方寻找地表，避免把下界基岩顶层当落点。半径固定100格，向上180格，高低变化随地表缓慢适应。先形成云底，再向下接地，约6秒完全成型，末尾2秒回收。成熟后沿初始朝向缓慢弯曲移动，约每秒0.5格；不是跟随施法者传送，也不会强制加载前方区块。风暴启用时清除原版全局雨幕，云底及沙尘、水雾、热流由风暴自身绘制，避免给沙暴和火龙卷叠加普通下雨。

## 四种环境变体

所有变体共用同一个风场和伤害算法：半径100格，形成开始3秒后每20tick结算5点基础伤害，仍受常规护甲、抗性和其他模组伤害事件影响。施法者、其坐骑、摄像头和自己的投射物不被风场吸卷。其他实体受到向内牵引、绕轴旋转及上升；高空转为向外抛离，包含无AI实体。实体离开/风消散后恢复正常重力和移动，没有永久改变AI或重力标记。

| 变体 | 场景判断与特殊效果 |
| --- | --- |
| 普通 | 其他地形；灰黑漏斗、碎屑墙，受影响生物短暂虚弱。 |
| 沙暴 | 沙地、荒地/恶地及数据包旱地标签；黄褐沙尘、沙砾风声，对范围内生物施加短暂失明和缓慢。 |
| 水龙卷 | 水面、海洋/河流及水域标签；青蓝水雾与上升水丝，扑灭实体和抽样地表火焰，不凭空制造洪水。 |
| 火龙卷 | 熔岩/岩浆块密集地表、超热维度及烈焰标签；烟柱、橙红热流，对生物施加短暂更强虚弱与发光，草地和木材抽样焦化。没有额外点燃实体，保持四变体相同基础伤害。 |

变体随中心环境每秒重新评估，不在轮盘硬选四种颜色。数据包可追加 `sourceofmystery:tornado_arid`、`tornado_aquatic`、`tornado_infernal` 群系标签，让其他模组群系参与判断。实际水/沙/熔岩表面也参与，不限于原版群系 ID。

## 破坏、物理和限制

松散地面、树叶/原木、木板、玻璃、羊毛等可被真实卷走，标签为 `sourceofmystery:tornado_movable`。默认每秒20次地表尝试，单个风暴最多96个短时碎块，使用每世界tick约2ms的共享地表软预算，最多每维度8场风暴；客户端最多绘制最近4场。每次破坏检查 `mobGriefing`、世界边界、玩家交互权限和 Forge `BlockEvent.BreakEvent`。默认不碰容器、机器、矿石、基岩或带方块实体的方块；标签可扩展，但硬度>6及不可破坏方块仍排除。

实际被移除或焦化的方块不自动回滚，风暴可破坏木结构建筑。碎块不掉落物品，约6秒后离场，结束时清理；保存后再加载会核对原风暴会话，防止永久悬空。风暴不跨服务器重启恢复；死亡、离线、换维度结束自己的风暴。风场不改变共享实体无重力标记；定身/冰冻等已有领域控制优先。

龙卷风没有用整块实心锥体代替：渲染为多层流动湍流片、环绕云团、宽地面碎屑墙、三个子涡旋和低空旋转云底。独立风雾着色器保留贴图色与柔和透明边缘，不沿用实体材质的硬透明裁切。靠近风暴临时覆盖原版云层的有效绘制选项，离开即恢复读取原设置，不改写玩家配置；不能据此保证所有第三方光影自带的体积云都受控制。云雾贴图和四套8秒风声为本地程序原创，音效包含低频轰鸣、间歇强风及对应沙砾/水浪/火焰细节。风声按距离和生成/消散强度变化，退出范围或结束即停止。游戏测试保持静音，解码/音频幅值检查不代表主观听感验收。

形态参考美国国家气象局的 [2013 El Reno 记录](https://www.weather.gov/oun/events-20130531)：最大宽度约2.6英里，具有多涡旋结构。本模组采用其宽漏斗、低云底和卷吸的视觉方向，游戏尺度仍为用户指定100格半径，没有声称模拟真实公里级流体力学。参考没有下载/复制灾害影像或其他模组资产。

## 配置与资产

服务端配置 `serverconfig/sourceofmystery-staff-server.toml` 的 `dimensionBreakerStaff`：

- `weather_control.energyCost`：晴雨雷暴2000；`weather_control.castTicks`：60。
- `weatherDurationTicks`：12000。
- `tornadoEnergyCost`：5000；`tornadoDurationTicks`：6000。
- `tornadoTerrainDamage`：true；`tornadoBlocksPerSecond`：20（0–100）。

网络协议12，两端需同版。法杖新增独立 `staff.weather` GeckoLib 动画，旧动作和几何保留；玩家抬杖引风并用空手转动控制阵。素材生成入口 `tools/staff/generate_weather_assets.py`；本地资产集中 `F:/ChatGPT/我的世界神秘之源模组开发/modeling/staff_weather/`，原始WAV、生成源与PNG/OGG分别保留。风柱为游戏运行时网格，无需Lux3D付费或将GLB误作运行资源。

隔离实测入口 `python tools/outsider/run_oculus_smoke.py --weather --vanilla --label <名称>`；移除 `--vanilla` 使用已有Oculus/Complementary，附加 `--video` 录制静音实机。正式包排除测试器。验证结果以 `build/staff-weather/release-verification.json` 为准，构建和单客户端通过不能替代完整整合包、真实双客户端及用户外观/音效验收。
