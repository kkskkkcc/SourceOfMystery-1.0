# 超次元法杖：时间魔法

按 L 选择「时间魔法」，Shift＋右键循环三个子类，松开 Shift 后右键释放。再次右键解除自己释放的时间魔法；三种模式均无持续时限。子类保存在当前法杖的 `SelectedTimeMagic` NBT 中。旧法杖的 `time_stop` 保存 ID、轮盘第 4 个位置和原有配置段保持兼容；没有子类标签时默认时间停止。

| 子类 | 当前维度世界速度 | 玩家 |
| --- | --- | --- |
| 时间停止 | 0 | 保留旧规则：施法者正常，其他玩家停止 |
| 时间延缓 | 0.1 倍 | 所有玩家保持正常操作与更新速度 |
| 时间加速 | 5 倍 | 所有玩家保持正常操作与更新速度 |

默认每次成功释放消耗 1000 神秘之能，无持续时限，手动解除后共享 60 tick 冷却（20 TPS 下 3 秒）。切换子类、失败和提前结束不再次扣费。三种模式都维持至再次右键解除。一个维度同时只能有一个时间魔法；不同维度可以独立施放。

## 更新范围

延缓每 10 个正常服务器 tick 运行一次完整维度模拟，加速每个正常服务器 tick 运行 5 次。使用实际的 `ServerLevel.tick`，同时按倍率派发 Forge 的维度前后 tick 事件。因此实体 AI、位移和寿命、随机方块 tick、红石／流体计划 tick、方块事件、方块实体／机器、自然生成、袭击、末影龙战斗、天气、昼夜以及本模组基于维度 tick 的法术任务遵循同一个维度时钟。玩家的实体 tick 每个正常服务器 tick 只运行一次；玩家背包、输入和服务器连接继续正常处理。

主世界的底层共享时间每个正常服务器 tick 仍推进一次，再通过每维度保存的偏移提供独立的游戏时间和昼夜时间。结束后继续沿用偏移，不补跑积欠的 tick。沿用旧 `sourceofmystery_time_stop` 存档数据及 `GameOffset`／`DayOffset` 字段，支持旧时停的时间偏移。活跃技能不跨重启恢复。

客户端同步子类、无限持续标志（remaining=-1，0仅表示结束）、维度、时间和会话 UUID，世界实体／方块实体动画 tick、粒子、动态贴图和云层更新按倍率推进。延缓的实体与粒子插值使用子 tick 相位，玩家插值保持正常；只有时间停止使用原有时停画面。结束消息核对会话 UUID，切换维度时清理旧客户端时钟，登录／重生／换维度同步当前时钟。网络协议升级为16，客户端和服务端必须使用同版。

## 配置

文件为世界的 `serverconfig/sourceofmystery-staff-server.toml`，均位于 `dimensionBreakerStaff`：

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `time_stop.energyCost` | 1000 | 时间停止费用，保留原配置 |
| `time_stop.castTicks` | 0 | 三个子类共同的法杖施法时长 |
| `timeStopTicks` | 240 | 旧配置兼容保留，不再控制时限 |
| `timeSlowEnergyCost` | 1000 | 时间延缓费用 |
| `timeHasteEnergyCost` | 1000 | 时间加速费用 |
| `timeSlowTicks` | 240 | 旧配置兼容保留，不再控制时限 |
| `timeHasteTicks` | 240 | 旧配置兼容保留，不再控制时限 |
| `timeStopCooldownTicks` | 60 | 结束后的共享冷却 |

两个新增倍率固定为0.1和5，费用独立可配置。三个旧持续时间键只为旧配置兼容保留，不再读取；所有模式均需再次右键解除。死亡、离线、离开当前维度和服务器关闭时清理，不把活跃状态跨重启恢复。冷却从解除时开始。

## 兼容边界

世界模拟与渲染更新受倍率控制，服务器主循环、联网、玩家区块可见性和必要的区块 IO 仍按正常节奏服务。异步读盘、世界生成线程及 GPU 的吞吐由硬件决定，不能承诺物理加载耗时精确变成十倍或五分之一。没有强行加载未加载区块。

通过实体／方块实体 tick 和 Forge 维度 tick 工作的模组会随该时钟更新；第三方模组自行使用的服务器全局事件、独立线程、系统实时时钟及自定义渲染时钟不保证自动受控。真实双客户端和完整整合包需要独立兼容验收，不能由构建成功或单客户端测试代替。

构建、实际倍率、扣费、自然到期、冷却及客户端验证见 `build/staff-time/` 和 `build/staff-time-smoke/` 的对应回执。测试使用独立世界，主音量为 0，不替换正式游戏实例。
