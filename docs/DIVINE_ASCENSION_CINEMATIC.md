# 神威天佑首次穿戴：登神

首次穿戴原 `sourceofmystery:divine_blessing_chestplate` 时，由服务端确认并向穿戴者单独发送 CG。只有该玩家调用摄像头；宇宙、天阶、悬浮胸甲和王座均为客户端舞台，不向世界放置方块或实体。玩家真实坐标保持原地，动画期间停止移动并阻止伤害及交互，结束恢复摄像头类型、视线、GUI 和原重力状态。

## 节奏与重看

全长 68.7 秒。0–8 秒从真实地表加速升空、穿云、显出地球弧面并拉远至轨道；8–18 秒在 NASA 地球外环绕并给玩家近景；18–23 秒揭示白色五阶；23–35 秒拾级而上；35–40 秒面对悬浮神甲；40–47 秒双手触甲；47–51 秒神光授甲并获得「登神」；51–59 秒观察身体；59–65 秒转向王座；65–68 秒凝视定格，随后黑场回到原地视角。

升空前段摄像头实际升离玩家所在地，同时俯视逐渐缩小的地形。2.35 秒开始进入有双层流动纹理的云带，3.6 秒在云中衔接本地球体场景，随后显出同一颗 NASA 地球的地平线、大气薄边及逐渐出现的星空。3.6–8 秒连续沿球体径向拉远，再把视线从地球弧面转向玩家；8 秒的眼位、视线及 FOV 与后续环绕机位连续。已删除旧版进入宇宙前的黑场遮罩，不再直接由高空黑场切到外太空。云中坐标衔接仍存在，真实世界没有被弯成球体。

玩家 CG 身体单独烘焙原版普通/纤细 PlayerModel，使用本人的皮肤及皮肤外层。原生装备和注册的附加渲染层继续绘制，过滤 MMD 身体替换层。Curios 等附加层接口有保留，但完整整合包的实际饰品效果仍须运行确认。

首次标记为神秘之能玩家持久数据中的 `divine_blessing_first_equip_v1`，重穿不会自动再播；原有数据克隆路径保留该标记。动画中按 Esc 可跳过。拥有 OP 2 权限、穿着胸甲时使用 `/somdivinecg` 可重看。异常退出有持久化重力恢复收据，下次登录清理；超时、死亡、换维度及退出也清理会话。

成就是服务器真实持久进度 `sourceofmystery:ascend_divinity`，并有本地六秒彩虹「登神」提示。动画音频包括升空、宇宙合唱/钟鸣、天阶显现、石阶脚步、触甲、授甲神光、装甲合身和王座低鸣八组原创程序音效。

## 用户提供的王座与最终比例

使用 `神秘之源素材/王座.zip` 内唯一的 `madmaggie_throne_01_static_LOD0.obj.glb`，保留原模型的 1713 三角面拓扑、5139 顶点及 UV；不再使用先前自制的 217 Cube 王座。原 GLB SHA256 为 `54d6aa4e2b458b9f2905e66677ffb417346336de95b7ac931eb5207b9266c925`。压缩包没有附带许可文件，不将此模型标为本模组原创。

按用户“比人大太多”和“只能灰白色”的要求，王座由原来 4.65 米高改为 **宽 1.65 × 高 2.30 × 深 1.50 米**。高度约为 1.8 米玩家的 1.28 倍，底座深度也收短，座面与扶手恢复接近人物可使用的体量。非等比缩放用逆转置矩阵处理光滑法线，UV 不改变。王座放在玩家终点身后 3.9 米，最终机位及头部朝向同步调整。

源贴图字节保留，游戏内材质转换为中性灰白：框架偏白，座面及靠背中灰，雕刻阴影深灰；所有输出像素 R=G=B，没有浅金、蓝色或其他彩色染色。纹理重载时动态材质自动失效重建。

GeckoLib 的标准 JSON 不接受此 GLB 的任意三角网格，因此以 `DivineThroneModel` 将顶点流烘焙为 GeckoLib GeoCube/GeoQuad，末顶点复制使第二个三角形退化，保留原始拓扑；通过 GeoObjectRenderer、骨架缓存和每顶点光滑法线渲染。运行资源为 `geo/cinematic/divine_throne.{geo.json,mesh}`，有单根骨与空闲控制器。`tools/divine/import_throne.py` 可从源 ZIP 重建；报告在 `art/divine_cinematic/imported_throne/import-report.json`。**不要再运行旧的 `generate_divine_throne.py` 覆盖导入版。**

地球采用 NASA Blue Marble 原始 2048×1024 图像，RGBA 转换保留 RGB 像素；来源与署名随纹理附在 `textures/cinematic/divine/CREDITS.txt`。官方来源：https://svs.gsfc.nasa.gov/2915/ 。其余舞台纹理和音频可由 `tools/divine/generate_cinematic_assets.py` 重建。

最终升空构建日志为 `build/divine-cg-ascent-silent-final-build.log`，原生游戏测试/录像目录为 `build/divine-cg-smoke/earth-ascent-silent-final/`。完整正常速度播放通过：首次穿戴、真实位置不变、摄像头/视线/GUI/重力恢复、第二次穿戴不重播、实际获得成就及升空/环绕机位连续性均通过，14个关键镜头含四个新增云层/地球过渡截图。测试主音量确认为0。地球弧面/拉远/轨道镜头实际捕获时间为4.913/6.407/7.808秒，所有升空关键镜头延迟不超过0.5秒。4020帧，中位16.7026ms，P95 18.6122ms，但仍有单帧814.8904ms峰值，不能宣称完全没有卡顿；报告 `divine-cg-verification.json` 保留实际值及截图时间。不能把视频的60fps编码参数当作实际运行帧率。

完整预览为 `art/divine_cinematic/divine-ascension-earth-ascent-preview.mp4`，前10秒单独预览为 `art/divine_cinematic/divine-earth-ascent-first-10s.mp4`。预览保留原创音轨，完整文件所有视频帧与音频解码检查通过，记录 `build/divine-cg-ascent-preview-checks.json`。仅导出，未自动播放声音。

上一灰白王座版 `gray-throne-final` 是64.7秒版本，已完整正常播放通过；先前 `supplied-throne-review` 是旧大尺寸彩色材质诊断截图；`epic-final` 和 `throne-review` 仍是被用户否定的自制椅子版本，不可混称为最新版。

`earth-ascent-final` 是升空改动首轮失败记录：完整画面录制后，恢复视线的测试断言失败，保存了 `Player view direction changed` 报告，不能当作通过。后续在玩家鼠标转向调用前消费正常鼠标增量并阻止 CG 期间转头，结束时再次恢复视线，避免黑场恢复的短间隔被鼠标改变方向。测试改为对比实际动画启动收据的视线，并按角度环绕差比较，而不是对比服务端收到装备请求前的客户端快照；失败时保留期望/实际角度。Earth 材质使用线性采样，改善近景 NASA 图像的硬像素边。

`earth-ascent-polished` 功能通过但有1.456秒单帧峰值，部分过渡截图延迟，不能当作最终升空镜头验收。随后缓存天空/地球单位球几何，去掉大气层逐顶点临时Vec3分配，镜头开始前预载纹理和灰白王座动态材质。`earth-ascent-release` 开头镜头仍超时失败，发现测试录像器在动画开始后初始化，现改在服务端穿戴前准备PBO/外部编码器；这项修正只在测试夹具，不进入正式包。最终 `earth-ascent-silent-final` 保留0.5秒镜头迟到断言且通过，未放宽成不检查。旧失败报告及录制保留。

按用户新要求，之后所有测试客户端默认主音量 0。两个隔离启动器都写入 `soundCategory_master:0.0`，不修改真实游戏实例的音量。正式 CG 仍有完整声音，预览视频保留音轨供用户自行检查；测试报告单独记录测试主音量为 0。

## 后续宇宙升空 CG 参考

用户指定参考：[轨道炮作者最新武器——SS-06 Gravitia](https://www.bilibili.com/video/BV1NZxv6rEwJ/)，并要求后续模组中同类震撼升空 CG 都可学习该参考。后续修改应先观看参考中实际的运镜、速度和空间尺度，再做自己的镜头设计，保留地表→高空→星球弧面→太空的可见连续过程。这里记录的是用户的审美方向，未引入该视频的模型、音频或代码。

本轮访问边界：浏览器成功读取视频页面及标题，但截图/播放器控制连续超时，公开元数据接口返回 HTTP 412，未完成逐帧观看。不能宣称已经复刻、完整分析过视频，也不能根据标题编造具体镜头。当前修改根据用户明确指出的地球过渡缺失来实现，后续能正常播放参考时再补充具体镜头分析。

## v3：人物表演、运镜与舞台模型（2026-11-06）

按新要求重做人物动作、舞台模型和运镜。升空（0–8 秒）、地球、王座、声音、成就、首次穿戴与重看逻辑不变。

- **关键帧轨道**：人物位置、朝向、六个身体部件的旋转和镜头都写在 `assets/sourceofmystery/cinematic/divine_ascension.json`，以剧情时间 20 Hz 采样。相同时间戳的两帧表示镜头切换。缺少该文件时自动回退到旧公式。
- **人物表演**：太空中低头看地球后抬眼；天阶升起时后仰；按左右交替抬腿、摆臂和前倾走上五级台阶；在神甲前手按胸口，再右手先行、双手触甲；授甲时离地约 0.3 米、张开双臂、仰头；随后察看护手和胸甲，站定；走三步到王座前，转身坐下，双手放上扶手，平视前方定格。
- **运镜**：环绕（4–8 秒，与升空衔接连续）、面部推近、天阶低角度揭示、登阶侧面跟拍、阶顶迎面英雄镜头、越肩看神甲、侧面触甲、授甲低角度弧线环绕、察看正面与俯视、跟随走向王座、王座正面缓慢后拉并收窄视角。
- **舞台模型**：原先的方块台阶替换为 GeckoLib 模型 `geo/cinematic/divine_stage.geo.json`：白玉台阶、金色踏步包边、每级云纹望柱与发光宝珠、斜向金栏杆、到达台太极圆盘、王座平台金边和八卦日芒地纹。台阶仍按原时序逐级升起。

生成与预览：

```text
python tools/divine/generate_cg_stage.py
python tools/divine/author_ascension.py --preview
```

`author_ascension.py` 定义动作与镜头，`preview_ascension.py` 生成离线透视预览拼图（`tools/gear/out/ascension_sheet.png`，不是游戏截图）。实机截图由 `gradlew runClient -PgearCheck` 在静音隔离世界中录制。
