# 超位权杖 v1

本次实现依据朋友提供的《新建文本文档.md》以及 Chat 中的两次补充确认。原有模组内容、界面和 Boss 数值保持原样。

## 已确认规则

| 内容 | 规则 |
| --- | --- |
| 获取 | 域外魔导师死亡掉落一把“传说中打破次元的超位权杖”，正常生物掉落规则下必掉 |
| 普通攻击 | 含玩家基础攻击力共 199 点；护甲、攻击蓄力等原版战斗规则仍适用 |
| 挖掘 | 生存模式持续挖掘约 0.9 秒；包括命令方块、末地传送门框架等硬度为负的方块；基岩除外 |
| 陨灭杀 | 消耗 10000；沿用 Boss 的吟唱、天空法阵、陨石轨迹、伤害与地形破坏逻辑；成功释放才扣费；取消不扣费；施法者不受自己的陨石伤害，吟唱期间可以受伤 |
| 裂地 | 消耗 8000；挥杖 3 秒；前方长 100、最宽 30 的渐缩裂缝，上界 Y=255，下达当前维度底部，保留基岩；有目标时播放 7 秒天空裂缝和黑剑；范围内造成 1000 真实伤害，排除施法者 |
| 大地悬浮 | 消耗 1000；选择前方区块，按每列地表向下取 50 格，向上移动 100 格；保留方块状态与方块实体数据 |
| 地形保存 | 裂地、悬浮永久改变地形；任务进度写入存档 |
| 时间停止 | 消耗 1000；立即生效；当前维度除施法者外的玩家、实体及世界模拟暂停 12 秒；开始时扭曲 1 秒，随后灰度；结束后再冷却 3 秒 |
| 空间撕裂 | 消耗 0；门户存在 10 秒；末地石到末地主岛，黑曜石到施法者有效下界重生点，主世界地表方块到有效主世界重生点；缺少有效重生点时使用目标维度默认出生区域 |
| 能量恢复 | 每秒恢复当前能量上限的 1%；小数累计；不增加上限；独立于每日回满开关 |

原版只保存一个当前重生点。重生点维度不符合门户目标时，按确认规则使用目标维度默认出生区域。传送支持普通实体和乘客关系；目标默认出生区域没有可站立位置时会补一个落脚平台。

## 操作与资源

主手或副手持杖时，默认 L 打开半透明法术轮盘。移动鼠标选择区域，点击或再次按 L 确认；按住 L 打开时，也可以移到法术上后松开 L 确认。按 Esc 关闭。右键使用当前法术，需要吟唱的法术持续按住右键。

模型使用 GeckoLib 4：银色长杖、四瓣弯曲杖冠、淡紫色晶体与双环，参考原有 Boss 权杖的形态。包含待机、吟唱、劈砍、悬浮、撕裂和时停六段独立动画。可编辑源文件是 `tools/staff/dimension_breaker_staff.bbmodel`，已经通过 Blockbench MCP 导入、修正并保存。

`tools/staff/generate_assets.py` 生成几何、动画和像素材质；`tools/staff/generate_audio.py` 生成五种法术各自的吟唱与释放音效，共十个原创合成片段，编码需要 PATH 中的 FFmpeg。重新生成素材后，需同步保存 Blockbench 工程中的对应编辑。

## 配置与实现

权杖配置位于存档 `serverconfig/sourceofmystery-staff-server.toml`，由 Forge 同步到客户端。攻击、挖掘时长、消耗、施法时长、裂缝尺寸与伤害、悬浮尺寸、时停与传送门时长均可配置。能量恢复比例位于原有 `sourceofmystery-common.toml` 的 `energy.regenerationPerSecond`，默认 `0.01`。

`staff/` 分别处理施法会话、地形任务、传送、时停和挖掘。客户端只提交选择和交互并播放视觉效果；消耗、伤害、地形及传送在服务端结算。网络协议从 4 更新为 5，联机双方需要安装同一版本。

裂地与悬浮按 tick 分批修改方块，避免一次修改整个体积。实际地形完成时间受服务器性能和区块加载影响。悬浮需要目标范围在世界高度内且没有方块阻挡，否则提示失败并不扣能量。

时停使用每个维度独立保存的模拟时间偏移，不修改服务器的实际 tick 计数，不把暂停时间补算给红石、流体和实体。Mixin 同时控制普通实体、其他玩家移动与交互、方块实体、随机及计划刻、生成与消失、客户端粒子、纹理和云层时间。

## 验证

项目固定使用 Java 17、Forge 1.20.1-47.4.20、GeckoLib 4.8.4。使用项目 Gradle Wrapper 执行：

```text
gradlew runGameTestServer
gradlew runClient -PstaffCheck
gradlew build
```

`StaffGameTests` 在独立测试世界验证能量累计、攻击和挖掘数值、命令方块实际挖掘、掉落、施法结算、自伤豁免、悬浮存档和箱子内容、跨维度时停、红石暂停与恢复、冷却、传送及裂地真实伤害。原有 Boss 和献祭传送门测试同时保留。

`StaffClientCheck` 只包含在开发测试运行中，会新建隔离世界并保存十四张实际客户端截图，覆盖第一/第三人称、轮盘、五种法术、时停扭曲与灰度恢复。测试类不打包进入发布模组。

2026-11-01 验证结果：

- `build`、`runGameTestServer` 和 `runClient -PstaffCheck` 成功完成。三组服务端集成测试全部通过，客户端输出 `STAFF_CLIENT_OK frames=14`。
- 已逐项检查实际截图中的轮盘、举杖姿势、土色杖头法环、天空巨剑、移动地块、画面扭曲、灰度及颜色恢复。截图位于 `build/staff-client-check/screenshots/`，完整运行日志位于 `build/staff-runtime-final.log`。
- 发布包为 `build/libs/sourceofmystery-1.0.0.jar`，已执行重混淆；检查了 Mixin 清单、映射文件和计划刻方法映射，确认不包含测试类。
- 所有资源 JSON 可解析；十个音效均为可解码的 Vorbis，时长与生成设置一致。Blockbench 工程内六段动画已与游戏资源核对。

需要玩家环境继续验收的是实际多人联机、其他模组或光影组合的兼容性，以及配乐音量和听感。当前自动测试及单人客户端验证不能替代这些体验结论。
