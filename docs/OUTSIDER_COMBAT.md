# 域外魔导师战斗 v2

v2 调整域外魔导师的动作与招式。伤害数值、动画、语音和湮灭陨星仪式保持不变。所有调节数值集中在 `OutsiderEntity` 顶部的常量中。

## 动作

| 项目 | 说明 |
| --- | --- |
| 受击反应 | 单次伤害不低于 120 时后仰约 0.5 秒，空中后退并转向攻击者。冷却 2 秒。陨星准备与仪式期间不触发。 |
| 环绕走位 | 以 9–13 格半径绕目标飞行，每 5–10 秒随机改变方向和半径。目标距离小于 6 格时升高到目标上方 5.5 格。 |
| 闪现 | 目标在 4 格内停留 2 秒后，闪现到目标 8–12 格外，留下传送门粒子与音效。冷却 8 秒。 |

## 招式

| 项目 | 说明 |
| --- | --- |
| 招式选择 | 不连续使用同一招式。远距离偏向黑暗之握，中距离偏向寂静之柱。湮灭陨星仅在生命低于 70% 后可用。脚下无地面时不选择寂静之柱。 |
| 黑暗之握 | 随机使用三种弹幕：左右扫射的扇形、螺旋、三轮横排波次。方向在起手后固定，不追踪目标。 |
| 寂静之柱 | 落柱前 0.5 秒在地面显示紫色标记。石柱以目标为中心排成 2–3 圈。目标在降落期间离开范围时，改为起飞并使用黑暗之握。 |
| 第二阶段 | 生命降至 40% 时进入。播放语音，双眼发光并持续散发粒子。普通招式冷却缩短 30%，湮灭陨星冷却缩短为 90 秒。 |

## 验证

客户端检查使用隔离世界，主音量为 0，玩家处于生存模式且不会受伤：

```text
gradlew runClient -PoutsiderCheck
```

检查依次触发闪现、受击反应和第二阶段，并记录约两分钟内的状态与招式切换。记录写入 `build/outsider-client-check/outsider-check.txt`，截图写入同目录的 `screenshots/`。
