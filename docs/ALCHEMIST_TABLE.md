# 炼金术士台

物品和方块ID：`sourceofmystery:alchemist_table`。拥有独立GeckoLib三维外观：黑曜石台体、金色镶边、双环祭品核心、药瓶和账本。原始本地Blender、GLB、GeckoLib、贴图及预览集中保存在 `F:/ChatGPT/我的世界神秘之源模组开发/modeling/alchemist_table`。没有云端付费生成。

## 合成和操作

工作台配方：

| 金锭 | 黑曜石 | 金锭 |
|---|---|---|
| 黑曜石 | 黑暗次元祭品 | 黑曜石 |
| 金锭 | 黑曜石 | 金锭 |

- 手持右键打开便携商店；潜行加右键方块表面放置。
- 放置后右键打开；徒手可采下并掉落一张台子。
- 所有20件商品同时展示，鼠标悬停显示完整商品名、材料、所需数量和当前拥有数量；左键兑换。
- 本功能只消耗标价材料，没有额外神秘之能费用。只使用主背包和快捷栏，不扣除穿戴装备、副手物品或改名/带自定义NBT的同类材料。

## 每日商品和价格

“每天”按主世界游戏日期计算，每24000日照时间tick跨日刷新。所有维度、玩家和台子共用当天清单；重复打开不刷新，同日物品和实际价格存入世界SavedData。睡觉或调整世界日照时间也会触发跨日。

每天随机选20种不同商品，输出每次一件，未设置限购。优先通过当前服务器配方和Forge材料标签寻找相关低级材料；价格在相应材料数量上限内随机，金块固定以1–9个金锭计价，材料块以相应锭、宝石或原材料计价，锭优先使用对应粒。

可识别其他模组注册物品、静态配方和通用材料标签。对必须依赖实际容器、动态NBT或不提供静态结果的配方安全跳过，不能声称任意模组的所有物品都支持。重新加载数据包会清理候选缓存，已生成的当日商品不重新抽取。

## 交易安全

服务端决定实际商品、数量和价格，客户端只发送菜单ID、商品编号及当日报价版本。扣材料和发货使用同一次背包计划提交；材料不足、背包无空位、过期报价或已关闭菜单均不会扣材料。展示格不可取出、克隆或快捷转移。持有条件失效或离开已放置台子8格后关闭菜单。

协议版本17，客户端与服务器均须使用同版模组。
