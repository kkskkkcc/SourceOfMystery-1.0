# 超次元法杖：领域展开

操作：L 选择「领域展开」，Shift＋右键循环五个领域，长按右键 2 秒展开；施法未完成时松开不扣费。成功展开消耗 5000 点神秘之能，持续 6000 tick（5 分钟）。再次按下右键可提前停止，无额外消耗；持杖看向可交互方块时也优先停止。持续按住施法键不会把刚展开的领域自动关闭。Shift＋右键在领域生效时仍只切换下一次的类型，不立即切换已经释放的领域。

**最新范围指令覆盖最初的独立数值：五种领域统一直径 200 格、半径 100 格。** 定身领域固定在释放位置；其余四种随施法者移动。范围按实体碰撞箱中心与领域中心的三维距离判定；斩杀按玩家当前朝向的前方半圆攻击。领域不强制加载远处区块，只处理已加载的实体和自然表面，不因为 200 格范围生成整片世界。

| 领域 | 效果 |
| --- | --- |
| 极寒 | 对范围内除施法者外的实体锁定位移；生物获得「极速冰冻」并每秒承受基础 3 点冰冻伤害，蓝冰外壳按照实体宽高绘制。地面逐步积雪，并持续播放寒风循环。施法者视野附近留出清晰区域，不增加遮眼雪幕或冰冻 HUD。 |
| 黑暗 | 施法者头顶 20 格处出现约 2.25 秒展开的黑洞，实体黑洞最大直径 5 格，外围吸积光环更宽。范围内实体以每秒 5 格向黑洞中心强制牵引，生物每秒承受基础 10 点伤害。随机吸收低级方块，留下真实缺口。 |
| 重力 | 生物获得原版漂浮与发光效果；补齐无 AI 生物、盔甲架及非生物实体的上升。原先已有的较强/较长效果优先保留，退出时清理领域追加的短效果并恢复记录的既有效果。 |
| 定身 | 固定在释放位置，范围内实体锁定位移，施法者免疫；施法者走动不改变领域原点。五分钟到期或手动停止时释放。 |
| 斩杀 | 前方范围内生物每秒承受基础 30 点斩击伤害和独立的 1% 最大生命真实伤害。真实伤害标签绕过护甲、护盾、抗性、附魔防护、伤害间隔和效果减伤，正常死亡事件与施法者归因保留。 |

普通基础伤害仍按 Minecraft/其他模组的护甲、抗性和伤害事件处理；每秒 3/10/30 是基础数值，斩杀的 1% 单独绕过常规减伤。没有用直接修改生命值伪造真实伤害。玩家免疫自己施放的领域；其他玩家可被影响，旁观者和摄像头 Marker 不受实体控制。冲突领域中，冰冻/定身/CG 锁定优先于黑洞牵引；领域约束保留实体正常 tick，以便受伤间隔、状态与生命结算继续进行。

## 斩杀开场 CG

CG 共 10 秒，只有施法者摄像头受到影响。其他玩家收到相同领域外观和人物动作，摄像头继续正常控制。实际法杖始终在原物品栏位置，只在人物/手持渲染中隐藏，不删除或重新发放物品。CG 中服务端锁定施法者位置并阻止伤害；结束、右键提前取消、死亡、离线、切换维度均清理状态并恢复摄像头、视角类型、GUI 和鼠标控制。无敌只覆盖开场 200 tick，后续领域持续期间不会保留。

0–0.7 秒拉出镜头；0.7–1.7 秒给结印手势近景；1.7–2.5 秒切面部；随后祭龛展开，镜头升到施法者身后较高位置，FOV 推到 130，持续展示红黑斩击。最后约半秒回归玩家原视角，避免最后一帧落到脚部。斩击从领域开始后约 2.4 秒进入演出，每秒伤害从第 3 秒起结算；CG 结束后领域、祭龛和持续斩击继续，直到五分钟或手动取消。

祭龛为本地设计的血月风格场景，以暗色檐顶、骨白边饰、立柱和红色刻印组成，共 97 个 GeckoLib 方块构件。使用本机 Blender 组装并保存可编辑源文件，保留 GLB 和与游戏一致的 GeckoLib 几何。参考题材的镜头节奏与气氛，不从其他作品游戏包提取资产。人物使用原版皮肤模型，保留装备和饰品层并省略手持物层。

## 方块、兼容与性能边界

黑洞默认仅选择数据包标签 `sourceofmystery:domain_absorbable`：泥土、草方块、粗泥土、沙、红沙、沙砾、石头、下界岩、末地石、雪块、黏土。其他模组可通过追加标签提供低级方块；默认不吸矿石、箱子、机器、基岩或带方块实体的方块。每 4 tick 尝试一个随机自然表面，最多保留 48 个待吸入方块。破坏前发送 Forge `BlockEvent.BreakEvent`，取消事件时不移除方块。不是对所有领地插件的全面兼容承诺。

冰壳、祭龛、法阵和斩击都是渲染层，没有把蓝冰或祭龛实体方块塞进世界。积雪和黑洞吸收是用户指定的实际地表改动，领域结束不会自动回滚。已加载的吸入碎块在结束时消失，卸载后再加载的碎块也会核对原领域会话，防止孤立的无重力方块残留。领域本身不跨服务器重启恢复；退出、死亡和换维度会结束施法者自己的领域。

默认配置在 `serverconfig/sourceofmystery-staff-server.toml`：

- `dimensionBreakerStaff.domain_expansion.energyCost`：5000。
- `dimensionBreakerStaff.domain_expansion.castTicks`：40。
- `dimensionBreakerStaff.domainDurationTicks`：6000，允许 200–72000。

旧六种法术 ID 和编号保持，「领域展开」追加为第七种，轮盘自动适配。领域版本将网络协议由 9 改为 10；后续陨灭杀准心索敌版本为 11，两端需同版。沿用现有 CC0 高清符文素材，出处见 JAR 中的 `STAFF_VFX_CREDITS.md`。寒风采用 Minecraft 原有灵魂沙峡谷环境循环，斩击采用扫击音；此次静音测试不代表主观音效已验收。
