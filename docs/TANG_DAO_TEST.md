# 唐刀测试物品

在「神秘之源」创造物品栏领取，或执行 `/give @s sourceofmystery:tang_dao`。物品使用原版普通物品的默认攻击属性，供模型和动作测试。

- 第一人称主手持唐刀、副手空闲时，左键依次接拔刀斜斩、反向挑斩、双手过顶下劈和向右横斩。出招后双手回到右侧立刀停势，最后一击收势后满 200 个游戏刻（正常速度 10 秒）自动回鞘。出鞘期间再次出招会重置等待时间。左右手镜像处理。
- 右手模式下，拔刀斜斩和反向挑斩相对上一版的画面角度绕准星分别逆时针转 30 度和 50 度，白色刀光跟随同一刀身轨迹。过顶下劈时双手合握刀柄，手臂和刀身从视野上方一起下移，刀尖随动作小幅转动。横斩的刀尖在过准星时向下转 90 度，刀锋由左向右先行。
- 挥刀和检视时，主手掌端对齐木柄握持段，副手回握时以柄尾为锚点。第一人称手臂直接使用 Minecraft 皮肤和原版模型尺寸，通过平移和旋转定位。
- 出鞘起手式绕刀身长轴逆时针转 90 度，使刃口朝向玩家前方。左手持刀时镜像刃口方向。
- 当前一刀没有接续输入时，尾势保留额外 20 个游戏刻（正常速度 1 秒）。有后续输入时直接接下一刀。剑光继续淡出，回鞘等待从收势完成后开始。
- 单手段在收势中先把刀送离双臂，副手从下侧绕行后重新握柄。白色剑光前沿使用当前刀刃和刀尖的变换，光弧的余迹取自更早的刃部轨迹。连招接续时保留上一招实际渲染的刀身翻转角度。
- 四段分别在动作内第 7、4、9、5 个游戏刻提交原版近战判定。击打帧使用游戏当时的准星拾取目标，刀身中段用手部渲染投影对准屏幕中心，随刀的白色剑光从这一帧开始。攻击距离、伤害和服务端处理沿用原版。
- 出鞘待机时按 `V` 检视，可在按键设置中修改。主手向前举刀展示刃面，副手沿刀身下方随动，再翻转展示另一面和环首，回到立刀双手停势。检视中按左键从当时的姿势接攻击。检视进行期间若达到回鞘等待时间，则在检视结束后回鞘。
- 第三人称待机时降低两手的握持位置，区分主手和副手。斜挂刀鞘参照乱石滩唐墓壁画中的佩刀轮廓，随躯干移动。第三人称挥刀沿用既有动作，副手占用时使用原版单手物品显示。
- 第一人称参考用户提供的「黑伤」展示视频中的攻击节奏、立刀构图和检视分段，使用唐刀自身模型和原创关键帧。刀和黑漆鞘沿用上一版加长后的网格。

构建使用 Java 17 和 Forge 1.20.1–47.4.20。游戏资源为 `assets/sourceofmystery/models/item/tang_dao*` 和共用的 `textures/item/tang_dao.png`。Blender 导出脚本保存在建模工作区 `modeling/han_ring_pommel_dao/source/export_minecraft.py`。

在模组源码根目录构建和启动独立验证环境。

```powershell
.\gradlew.bat build shaderCheckJar --offline --console=plain --no-daemon
python tools/outsider/run_oculus_smoke.py --tang-dao --vanilla --label vanilla-arm-native
python tools/outsider/run_oculus_smoke.py --tang-dao --label vanilla-arm-shader
```

验证使用隔离世界及程序触发的原版攻击键和检视键。记录客户端四次击打帧、两种主手设置下刀身穿过准星的投影、每次击打的刀锋方向、集成服务端伤害次数，以及待机、检视和回鞘的实机画面。测试同时检查命中前后的刀锋角度，避免回腕期间出现瞬间翻面。物理鼠标操作与实际整合包兼容性留待玩家验收。
