# 来自东方的术

超次元法杖轮盘新增第九项，放在外圈。右键持续蓄力默认20tick（1秒），最多20tick，完成后消耗 5000 神秘之能；提前松开不扣费。不再接管任何玩家摄像头、隐藏HUD、固定位置或赋予CG无敌；玩家始终正常移动、转头与操作。五门展开和法球充能随后持续58tick，再发射法球；从按下右键开始共78tick，正常20TPS下约3.9秒。旧配置中60或更大的castTicks会按20执行，提前松开仍可取消。按住右键到充能完成后不重复尝试启动，也不误报“无法启动”。

五道橙红色粒子神门在施法方向由近及远升起，完成后固定在原位置。门体没有实体模型、碰撞或方块，采用批量发光粒子绘制；白色法纹、双层纯白法球和声音为本项目生成的素材。旧 Blender 神门方案已被用户否决，仅存档在建模目录的 drafts/rejected-mesh-v1，运行时不引用。参考视频无法读取，设计依据是用户提供的截图；外观仍待用户验收，不能宣称一比一通过。

法球半径10格，按蓄力完成时的准心方向（完整yaw/pitch，包含上下方向）定向；五门定格后不因玩家后来转头或移动而转动。球心从释放原点沿施法轴前移16格、沿该轴局部上方向偏移8格处发射，水平施法仍等于前方16、上方8格。粒子门、法球、尾迹和实体裹挟使用同一空间方向。**255 格射程从发射时球心计算**，不是从玩家脚下计算；默认每模拟 tick 前进 1.4 格。球体外沿自然覆盖球心路径外 10 格。

碰到实体后造成一次 1000 点魔法伤害，法球继续前进，并将仍存在的实体一起裹挟飞行；同次施法不会重复造成这 1000 点伤害。施法者和禁止 PVP 的玩家不被命中。实体原有重力状态会被保存；抵达射程、撞击不可破坏方块、施法者死亡或离开维度、世界卸载时释放并恢复。异常退出留下的临时无重力标记会在实体重新载入时恢复。单个法球最多裹挟 256 个实体。

路径中的可破坏方块直接抹除，不产生掉落，容器内容随方块清除。碰到基岩等硬度为负的方块，按球体前沿的连续碰撞提前终止；世界边界、交互权限或其他模组取消 BreakEvent 时，也停止法球并保留受保护方块。方块处理有每 tick 数量及 3ms 共享预算，因此清除队列可能稍晚于球体到达。不会强制加载区块；未加载区域不保证地形清除或实体命中。

配置位于现有 COMMON 配置的法杖分组：`easternBlocksPerTick`（飞行速度）、`easternTerrainErasure`、`easternEraseAttemptsPerTick`。射程固定 255。网络协议16，服务端和客户端需同版。

静音原生 Forge 回归记录、视频和候选包在 `build/eastern-rite/` 与 `build/eastern-rite-smoke/`。具体通过项以最终 release-verification.json 为准；编译不等于实机通过，实机行为通过也不等于用户外观验收。测试不替换用户实例的 JAR 或声音设置。
